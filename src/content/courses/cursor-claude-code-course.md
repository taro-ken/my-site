# 講座: Cursor / Claude Codeで、未経験からアプリをつくる

**ゴール**: プログラミング未経験でも、Cursor / Claude CodeなどのAIコーディングツールを使い、実際に動くアプリ(習慣トラッカー)を1つ完成させ、公開するところまで体験する。

**制作方針**
- 台本: Claudeが執筆
- スライド: [Gamma](https://gamma.app/) にテキストを貼って自動生成
- スクリーンショット: taroが実際にツールを操作して撮影
- ナレーション音声: [ElevenLabs](https://elevenlabs.io/ja)(Eleven v3、日本語)で台本を読み上げ
- 編集・字幕: CapCut

**題材**: 全レッスンを通じて「習慣トラッカー(毎日の習慣を記録し、継続日数が見えるシンプルなWebアプリ)」を一貫して作っていく。

## 第2章 企画編 - 何を作るか決める

### レッスン2: 個人開発で成功しやすいテーマの選び方

**スライド1**
表示: 「個人開発で失敗しやすいテーマ / 成功しやすいテーマ」

ナレーション:
このレッスンでは、実際に何を作るかを決めていきます。個人開発で失敗しやすいのは、いきなり大きすぎるものを狙うことです。逆に成功しやすいのは、「自分自身が欲しいと思える、小さいもの」です。

**スライド2**
表示: Essence・Minimaのスクリーンショット

ナレーション:
私自身、Essenceは自分のためのセルフケアアプリとして、Minimaは自分の持ち物を管理するために作りました。どちらも、最初は「自分が欲しかったから」という理由だけで始めています。

📸 スクショ⑦(任意): Essence・Minimaのホーム画面

**スライド3**
表示: 「今回のお題: 習慣トラッカー」

ナレーション:
この講座では、題材として「習慣トラッカー」を一緒に作っていきます。毎日の習慣を記録し、継続日数が見えるだけの、シンプルなWebアプリです。理由は3つあります。誰もが欲しいと思えるテーマであること、機能が最小限で済むこと、そして実際に多くの個人開発アプリが、この形から有料化に成功していることです。

### レッスン3: AIへの「指示の出し方」

**スライド1**
表示: 「悪い指示 / 良い指示」

ナレーション:
AIコーディングツールは、指示の出し方次第で、出てくる結果が大きく変わります。

**スライド2**
表示: 悪い例「アプリを作って」

ナレーション:
例えば、「アプリを作ってください」だけでは、AIは何を作ればいいか分かりません。

**スライド3**
表示: 良い例(具体的な指示文)

ナレーション:
「習慣の名前を入力して登録できる、シンプルなWebアプリを作ってください。登録した習慣は一覧で表示し、今日達成したらチェックできるようにしてください」というように、誰が・何を・どう使うかを具体的に伝えることが大切です。

📸 スクショ⑧: CursorまたはClaudeデスクトップアプリのCodeタブに、この具体的な指示文を入力した画面

**スライド4**
表示: 「ポイント: 一度に全部を頼まない」

ナレーション:
もう1つ大切なのは、一度に全部を頼まないことです。まずは最小限の形を作ってもらい、動くことを確認してから、少しずつ機能を足していきます。

### レッスン4: 画面・機能を1枚の設計書にまとめる

**スライド1**
表示: 「作る前に、1枚にまとめる」

ナレーション:
コードを書き始める前に、何を作るかを1枚の文章にまとめておくと、AIとのやり取りがスムーズになります。

**スライド2**
表示: 習慣トラッカーの設計メモ(箇条書き)
- 画面は2つ: 登録画面、一覧画面
- 習慣の名前を登録できる
- 一覧で、今日分をチェックできる
- 継続日数を表示する

ナレーション:
今回の習慣トラッカーは、この4行だけで十分です。画面は登録画面と一覧画面の2つ。習慣の名前を登録でき、一覧で今日の分をチェックでき、継続日数を表示する。これをそのままAIに渡します。

📸 スクショ⑨(任意): このメモをテキストファイルやメモ帳にまとめた画面

**スライド1**

**スライド2**
表示: スクショ⑫(エラー画面)

ナレーション:
例えば、チェックを入れても継続日数が増えないという不具合が出たとします。
